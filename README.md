# DComp320 Data Structures and Algorithm — Stack Expression Evaluator

## 1. Project Overview
This project implements the DComp320 assignment using a custom **Stack** data structure. The program reads arithmetic expressions from `input.txt`, evaluates them using stacks, and writes the results to `output.txt`.

Supported operators:
- Addition: `+`
- Subtraction: `-`
- Multiplication: `*`
- Division: `/`
- Parentheses: `(` and `)`

The evaluator also supports decimal values and negative numbers.

## 2. Files
- `stack_expression_evaluator.py` — complete Python source code.
- `input.txt` — sample input supplied in the assignment format.
- `output.txt` — output generated by the program.
- `README.md` — instructions and design notes.


## 3. How to Run
1. Install Python 3.9+.
2. Place all files in the same folder.
3. Open a terminal in the project folder.
4. Run:

```bash
python stack_expression_evaluator.py
```

5. The program creates/updates `output.txt`.

## 4. Input Format
Each mathematical expression is placed on its own line. Expressions may be separated by a line containing a separator, for example:

```text
3 + 5 * 2
----
(8 / 4) + 7 * 2
----
10 - (2 + 3) * 4
```

The program preserves the separator lines in the output.

## 5. Output Format
For the sample input, the mathematically correct output is:

```text
13
----
16
----
-10
```

### Important note about the assignment's printed example
The assignment image appears to show `17` for `(8 / 4) + 7 * 2`. However:

`(8 / 4) + 7 * 2 = 2 + 14 = 16`

Therefore, the implementation outputs **16**, which is the mathematically correct result. This discrepancy should be mentioned to the lecturer if clarification is required.

## 6. Design
The program uses two stacks:
- **Value stack:** stores numbers and intermediate results.
- **Operator stack:** stores operators and parentheses.

Operator precedence is:
1. `*` and `/`
2. `+` and `-`

Parentheses have the highest grouping priority.

## 7. Complexity
For an expression containing `n` tokens:
- Time complexity: **O(n)**
- Space complexity: **O(n)**

Each token is processed a constant number of times, and each stack operation (`push`, `pop`, `peek`) is O(1).

## 8. Error Handling
The program reports invalid expressions, mismatched parentheses, invalid characters/numbers, and division by zero as `ERROR: ...` instead of terminating unexpectedly.
